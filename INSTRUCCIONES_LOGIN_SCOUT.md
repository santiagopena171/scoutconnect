# 🎯 INSTRUCCIONES - SISTEMA DE LOGIN MEJORADO

## ✅ Sistema de Login con Selección de Tipo de Usuario

### 🚀 Cómo funciona el nuevo sistema:

1. **Abrir la aplicación** en cualquier navegador
2. **Ir a la página de login**: `login.html`
3. **Seleccionar tipo de usuario**: Scout/Ojeador o Futbolista
4. **Introducir credenciales** según el tipo seleccionado
5. **Redirección automática** al dashboard correspondiente

### 🎯 Tipos de Usuario Disponibles:

#### 🔍 **SCOUT/OJEADOR**
- Seleccionar opción "Scout/Ojeador"
- Redirige a: `dashboard-scout.html`
- **Credenciales específicas**:
  - `scout@scoutconnect.com` / `scout123`
  - `ojeador@scoutconnect.com` / `scout123` 
  - `scout1@scoutconnect.com` / `scout123`
- **Demo general**: Cualquier email válido + contraseña (min. 6 caracteres)

#### ⚽ **FUTBOLISTA**
- Seleccionar opción "Futbolista" 
- Redirige a: `dashboard-futbolista.html`
- **Credenciales específicas**:
  - `futbolista@scoutconnect.com` / `futbol123`
  - `jugador@scoutconnect.com` / `futbol123`
  - `player@scoutconnect.com` / `futbol123`
- **Demo general**: Cualquier email válido + contraseña (min. 6 caracteres)
